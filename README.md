# ⚡ Диспетчерська генератора MTservice (Telegram Mini App)

Сучасний веб-додаток **Telegram Mini App** та бот для автоматизації обліку роботи генераторів електроенергії на об'єктах: фіксація запусків та зупинок, автоматичний розрахунок мотогодин, облік витрати та заправок пального, контроль планового технічного обслуговування (ТО) та вивантаження звітів в Excel.

> 🇺🇦 **Повна локалізація для України:**
> - Часовий пояс: **Київський час (`Europe/Kyiv`, UTC+2 / UTC+3)**
> - Валюта: **Українська гривня (`₴`)**
> - Мова інтерфейсу, звітів та сповіщень: **Українська**

---

## 🌟 Основний функціонал

1. **📱 Повнофункціональний Telegram Mini App**:
   - Адаптивний табло-інтерфейс у нативному стилі Telegram (підтримка темної та світлої тем, тактильний відгук Haptic Feedback).
   - Живий пульсуючий індикатор статусу (🟢 **В РОБОТІ** / 🔴 **ЗУПИНЕНО**) з лічильником часу роботи в реальному часі.
   - Візуалізація рівня пального в баку з графічною шкалою, відсотками та розрахунком прогнозованого часу автономної роботи.
   - Великі зручні кнопки запуску/зупинки з можливістю корекції часу (наприклад, «-15 хв» чи «10:30»).

2. **⛽ Облік пального та заправок**:
   - Автоматичне списання пального за паспортною нормою (л/год $\times$ час роботи).
   - Зручна модальна форма заправки (об'єм у літрах, вартість у ₴, джерело/номер чека).
   - Журнал заправок з динамічним перерахунком залишку в баку.

3. **🔧 Контроль сервісу та планового ТО**:
   - Автоматичний зворотний відлік мотогодин до наступного ТО.
   - Статуси: 🟢 В нормі, 🟡 Скоро ТО (менше 20 мч), 🔴 Прострочено!
   - Фіксація виконаних регламентних робіт (заміна мастила, фільтрів, вартість) зі скиданням та оновленням лічильника ТО.

4. **📊 Звіти та вивантаження в Excel**:
   - Зведення ключових показників за сьогодні та за поточний місяць.
   - Одноклікове завантаження структурованого звіту **Excel (`.xlsx`)** зі сторінками: *Зведення*, *Журнал запусків*, *Заправки*, *Обслуговування (ТО)*.

5. **⚙️ Панель адміністратора**:
   - Калібрування фізичного лічильника мотогодин (за тахометром генератора).
   - Тарування фактичного залишку пального в баку.
   - Налаштування паспортної норми витрати, місткості бака та інтервалу між ТО.
   - Управління операторами та правами доступу.

6. **🔔 Дежурні Telegram-сповіщення**:
   - Попередження при безперервній роботі генератора понад 8 годин.
   - Тривога при критичному залишку пального (< 15%).
   - Нагадування про прострочене планове ТО.

## 🛠 Технологічний стек

- **Бекенд:** Python 3.10+ (FastAPI + Uvicorn)
- **Telegram бот:** aiogram 3.x
- **База даних:** **PostgreSQL 16** (через асинхронний драйвер `asyncpg` + SQLAlchemy 2.0; автоматичний fallback на SQLite при автономній розробці)
- **Кеш:** **Redis 7** (швидке кешування дашборду; автоматичний fallback на in-memory кеш)
- **Фронтенд:** Telegram Mini App (HTML5, CSS3 Glassmorphism, Vanilla JS, Telegram WebApp SDK)
- **Звітність:** OpenPyXL (генерація стилізованих таблиць .xlsx)
- **Контейнеризація:** Docker + Docker Compose

## 🚀 Запуск проєкту

### Варіант А: Швидкий запуск через Docker Compose (Рекомендовано)

1. Скопіюйте файл налаштувань:
   ```bash
   cp .env.example .env
   ```
2. Відкрийте `.env` та вкажіть ваш `BOT_TOKEN` від [@BotFather](https://t.me/BotFather) та ваш ID у `ADMIN_IDS`.
3. Запустіть весь стек (Postgres + Redis + App):
   ```bash
   docker compose up -d --build
   ```
4. Додаток автоматично запуститься на порту `8080`.

---

### Варіант Б: Локальний запуск (Python venv)

1. Створіть віртуальне оточення та встановіть залежності:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Налаштуйте `.env`:
   ```powershell
   cp .env.example .env
   ```

3. Запустіть єдину точку входу (підніметься і FastAPI Mini App на порту 8080, і Telegram-бот):
   ```powershell
   python -m bot.main
   ```

## 🌐 Підключення Telegram Mini App

Для того, щоб Telegram відкривав додаток з мобільного клієнта або ПК:
1. Запустіть тунель для вашого локального порту `8080` (наприклад, через ngrok або Cloudflare Tunnel):
   ```bash
   ngrok http 8080
   ```
2. Скопіюйте отриману HTTPS-адресу (наприклад, `https://abc-123.ngrok-free.app`) і вкажіть її у файлі `.env`:
   ```env
   WEBAPP_URL=https://abc-123.ngrok-free.app
   ```
3. У [@BotFather](https://t.me/BotFather) налаштуйте кнопку меню:
   - Відправте `/setmenubutton`
   - Виберіть вашого бота
   - Вкажіть URL вашого Mini App (`https://abc-123.ngrok-free.app`)
   - Вкажіть назву кнопки: `⚡ Генератор`

Тепер у чаті з ботом завжди буде активна кнопка Mini App, яка відкриває інтерфейс управління!
