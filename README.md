# ⚡ Telegram-бот учета работы генератора и расхода топлива (MTservice)

Бот предназначен для автоматизации контроля работы дизельных и бензиновых генераторов на объектах: фиксация запусков и остановок, учет моточасов, автоматический расчет расхода топлива по норме, контроль остатка в баке, планирование ТО и выгрузка отчетов в Excel.

---

## 🎯 Основные возможности

1. **⚡ Запуск и остановка генератора**:
   - Фиксация старта и остановки одной кнопкой.
   - Возможность указать фактическое время (например, `-15` минут назад или `10:30`), если оператор включил генератор раньше, чем нажал кнопку в боте.
   - Защита от повторного запуска или ошибочной остановки.

2. **⏱ Точный учет наработки (моточасов)**:
   - Автоматический подсчет продолжительности работы каждой рабочей сессии.
   - Ведение общего счетчика наработки генератора (нарастающий итог).

3. **⛽ Учет топлива и расхода**:
   - Расчет расхода топлива по паспортной норме (литров в час $\times$ время работы).
   - Автоматическое списание израсходованного объема из текущего остатка в баке.
   - Журнал заправок с указанием залитого объема, остатка до/после и комментариев (номер чека, источник топлива).
   - Визуальная шкала уровня топлива (прогресс-бар) и предупреждение о низком остатке.

4. **🔧 Контроль технического обслуживания (ТО)**:
   - Отслеживание оставшихся моточасов до следующего планового ТО.
   - Цветовая индикация статуса: 🟢 В норме, 🟡 Скоро ТО (менее 20 мч), 🔴 Просрочено!
   - Фиксация проведения регламентных работ (замена масла, фильтров) со сбросом интервала.
   - Журнал истории выполненных ТО.

5. **📈 Аналитика и выгрузка в Excel**:
   - Быстрая сводка за сегодня и за текущий месяц (число запусков, время работы, сожженное и заправленное топливо).
   - Выгрузка красивого форматированного файла Excel (`.xlsx`) со страницами:
     - *Сводка* (ключевые метрики генератора);
     - *Журнал запусков* (время старта/стопа, моточасы, расход, кто запустил/остановил);
     - *Заправки* (дата, объем, кто заправил, примечания);
     - *Обслуживание (ТО)* (моточасы, проведенные работы, исполнитель).

6. **👥 Разграничение прав и безопасность**:
   - Роли пользователей: `Администратор`, `Оператор`, `Ожидает одобрения`, `Заблокирован`.
   - При первом запуске новый пользователь отправляет запрос: администратору приходит уведомление с кнопками «Одобрить» / «Заблокировать».
   - Доступ к калибровке счетчиков и изменению настроек открыт только администраторам.

7. **🔔 Фоновый мониторинг (дежурные уведомления)**:
   - Оповещение при непрерывной работе генератора более 8 часов.
   - Предупреждение о критическом остатке топлива (< 15%).
   - Напоминание о необходимости проведения планового ТО.

## 🛠 Технологический стек

- **Python 3.10+** (протестировано на Python 3.14)
- **aiogram 3.x** (современный асинхронный фреймворк для Telegram Bot API)
- **SQLAlchemy 2.0 (asyncio) + aiosqlite** (асинхронная работа с SQLite)
- **OpenPyXL** (генерация форматированных отчетов Excel)
- **Pydantic Settings** (типизированное управление конфигурацией через `.env`)

## 🚀 Быстрый старт

### 1. Подготовка окружения

Если виртуальное окружение еще не создано:

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка параметров (.env)

Скопируйте пример конфигурации и заполните ваши данные:

```powershell
cp .env.example .env
```

Отредактируйте `.env`:
- `BOT_TOKEN`: токен вашего бота (получить у [@BotFather](https://t.me/BotFather)).
- `ADMIN_IDS`: ваш Telegram ID через запятую (узнать свой ID можно у [@userinfobot](https://t.me/userinfobot)).
- `GENERATOR_NAME`: название генератора (например, `SDMO 100 кВА` или `Основной ДГУ`).
- `INITIAL_TOTAL_HOURS`: начальные моточасы на физическом счетчике генератора (например, `142.5`).
- `FUEL_RATE_PER_HOUR`: паспортный расход (л/час, например `4.5`).
- `TANK_CAPACITY`: емкость бака в литрах (например, `150.0`).
- `INITIAL_FUEL_LEVEL`: текущий остаток топлива в баке.
- `MAINTENANCE_INTERVAL_HOURS`: периодичность ТО (например, `250.0`).
- `TIMEZONE`: часовой пояс объекта (например, `Europe/Moscow`).

### 3. Запуск бота

```powershell
python -m bot.main
```

Или через виртуальное окружение:

```powershell
.\venv\Scripts\python.exe -m bot.main
```

База данных SQLite создастся автоматически при первом запуске в директории `data/generator.db`.

## 📱 Как пользоваться ботом

1. Откройте диалог с ботом в Telegram и отправьте команду `/start`.
2. Если вы указали свой ID в `ADMIN_IDS`, вы сразу получите доступ с правами Администратора.
3. В нижнем меню доступны кнопки:
   - **▶️ Запустить генератор** — подтверждение старта в реальном времени либо ввод времени запуска. Кнопка сменится на **⏹️ Остановить генератор**.
   - **📊 Статус** — отображение текущего состояния, уровня топлива с графическим индикатором, времени работы и счетчика до ТО.
   - **⛽ Заправка** — ввод количества залитых литров с пересчетом остатка в баке.
   - **🔧 ТО** — информация о регламенте, кнопка фиксации выполненных работ и история ТО.
   - **📈 Отчеты** — статистика за сегодня, за месяц, последние операции и скачивание полного Excel-файла.
   - **⚙️ Настройки** *(только для админа)* — калибровка моточасов, корректировка бака, изменение нормы расхода и подтверждение новых пользователей.
